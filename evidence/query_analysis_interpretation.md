# Query analysis — interpretation of the reproducible benchmark

The benchmark script creates a deterministic synthetic workload of 1,000 books, 1,500 physical copies, 3,000 members, 8,000 loan headers and 12,000 loan-item history rows. It measures four representative access patterns before and after adding workload indexes. Each query is warmed up and timed 15 times; the median is reported. `EXPLAIN QUERY PLAN` output is captured before and after indexing.

The figures in `benchmark_summary.csv` and `benchmark_results.json` are generated by the accompanying script. They are environment-specific local measurements, not production guarantees. Small millisecond timings can vary with hardware, SQLite version, cache state and system load. Interpret the query plans alongside the timings, and repeat the experiment with production-like data before making operational claims.
